# PRD: 한글 줄바꿈 바로잡기

## 무엇이 문제인가요
한글 문장이 화면 끝에 닿으면 **단어 한가운데에서** 다음 줄로 넘어갑니다.

> 우리반 보드에서 쓰는 선생님 비밀번호로 로그인하세
> 요.

웹 브라우저는 기본적으로 한글을 "글자 하나하나가 끊어도 되는 자리"로 여기기 때문입니다. 영어는 띄어쓰기에서만 줄을 바꾸는데, 한글은 아무 글자 사이에서나 바꿔 버립니다.

## 어디에서 생기나요
앱 전체입니다. 화면 폭이 좁을수록(학생 휴대폰) 더 자주 보입니다.
- 선생님 화면: 로그인, 퀴즈 만들기, 퀴즈 목록, 결과표, 안내 문구
- 학생 휴대폰 화면: 입장, 문제, 보기, 결과
- 큰 화면(게임 진행): 10개 게임 모드의 문제·보기·안내 문구
- 퀴즈 런 모드의 정답 문(그림으로 그려지는 글자)도 글자 단위로 끊고 있었음

## 무엇이 "완료"인가요
1. 한글 문장은 **띄어쓰기 자리에서만** 줄이 바뀝니다. ("로그인하세요."는 한 덩어리로 다음 줄로 넘어감)
2. 띄어쓰기 없이 아주 긴 말(긴 인터넷 주소, 아주 긴 닉네임 등)은 화면 밖으로 삐져나가지 않고, 그때만 글자 중간에서 끊깁니다.
3. 좁은 휴대폰(폭 320px)부터 큰 화면까지 화면이 옆으로 밀리거나 글자가 잘리지 않습니다.
4. 퀴즈 런의 정답 문 글자도 띄어쓰기 자리에서 줄이 바뀝니다.
5. 앞으로 새 화면을 만들어도 저절로 지켜지도록 규칙이 저장소에 남아 있고, 점검 스크립트(`node tests/check.js`)가 규칙이 빠졌는지 확인합니다.

## 하지 않는 것
- 문장 내용(문구) 자체를 바꾸지 않습니다.
- 글자 크기나 디자인은 바꾸지 않습니다.
