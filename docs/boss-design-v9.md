# 반짝퀴즈 v9 보스 디자인 계약
목표: "진짜 보스 몬스터를 잡는다"는 느낌. 귀여운 얼굴 대신 위압감 있는 판타지 게임 보스(초등학생용이라 피·잔혹 표현 없음, 무섭지만 멋있게). 게임과 맵 테마에 꼭 맞는 디자인·이름·공격.
공통 품질 기준:
- 직접 그린 SVG(외부 이미지·라이브러리 금지). 여러 겹 그라데이션, 발광(feGaussianBlur glow), 테두리 하이라이트, 그림자, 뿔·갑옷·결정·촉수 등 실루엣이 확실히 다르게. 크기감(화면을 압도).
- 대기 애니메이션: 숨쉬기, 눈·코어 발광 맥동, 오라/입자(불씨·눈송이·번개·연기), 일부 부위 움직임. 피격 시 흰 섬광+움찔, 체력 낮으면 균열·불꽃 등 손상 표현.
- 등장 연출(보스 인트로): 화면 어두워짐 → 경고 → 보스 실루엣 → 번쩍이며 정체 공개 → 큰 이름 카드("칭호" 작은 글씨 + 이름 큰 글씨, 비스듬한 띠, 테마 색). 약 2.5~3.5초. reduced-motion 이면 간단히.
- 쓰러질 때: 테마에 맞는 폭발/소멸(용암 분출, 얼음 산산조각, 연기로 흩어짐 등).
- 한국어, 이모지 금지, 다른 작업자 파일 수정 금지. 성능: 휴대폰에서도 부드럽게(필터 남발 금지, 큰 영역 blur 는 1~2개).

## A. 보스 레이드 (arena-orig.js/.css 의 boss 부분만. 보물 창고 arena-loot.js 와 보물상자·꽃밭은 그대로)
엔진의 `modeState.level`(1부터)과 `bossName` 을 씀. 엔진 이름(부모가 engine.js 에 넣음, level 순서):
1. 화염의 군주 이그니스 — 용암 바위 몸, 갈라진 틈의 용암 빛, 불꽃 왕관. 무대: 화산 분화구. 반격: 화염 숨결/용암 비
2. 눈보라 마수 블리자르 (v11에서 "빙결 여제 프로스티아"에서 이름 변경) — 얼음 결정 갑옷의 골렘, 서리 날개, 차가운 푸른 눈. 무대: 얼음 동굴(오로라). 반격: 얼음 창 비/눈보라
3. 심연의 크라켄 — 거대 문어, 빛나는 무늬의 촉수 여러 개, 큰 외눈. 무대: 깊은 바다. 반격: 촉수 내려치기/소용돌이
4. 천둥 거신 볼테우스 — 구름 위 거인, 번개 문양, 번개 망치. 무대: 폭풍 산꼭대기. 반격: 낙뢰
5. 그림자 용 녹투르 — 검보라 용, 날개, 보라 불꽃. 무대: 어둠의 성. 반격: 그림자 화염
6. 강철 파괴신 메카트론 — 거대 전투 로봇, 코어 동력로, 미사일 포드. 무대: 폐허 공장. 반격: 미사일 일제 사격/레이저
7. 혼돈의 마왕 카오스 — 최종 보스, 여러 원소(불·얼음·번개)가 섞인 왕관과 망토, 거대한 두 손, 차원 균열 배경. 반격: 혼돈 운석
- 보스 수가 3~6 마리인 게임은 1번부터 차례로 나오고 마지막 보스에는 "최종 보스" 표시. 문제 수가 많아 7마리면 7번이 최종.
- level 별 무대 배경도 바꿈(진행자 큰 화면). 작은 칸·학생 띠에서도 알아볼 수 있게 얼굴/상반신 아이콘 버전.
- 기존 기능 유지: 피격 숫자, 치명타, 화남/분노 단계, 반격 임팩트(이제 보스별 공격 모양), 학생 오답 피격 화면, 처치 카운트, 끝 카드.

## B. 퀴즈 런 맵 보스 (arena-runner.js/.css 만)
보스 맵(화산·정글·우주)마다 맵에 맞는 보스, 다시 같은 맵에 오면(두 바퀴째) "강화형"(색·오라 강화, 이름 앞 "분노한"):
- 화산: 용암 거인 마그마론 (용암이 흐르는 바위 거인, 불꽃 주먹, 용암 돌 던지기)
- 정글: 정글의 폭군 콩가 (거대 고릴라 전사, 나무 갑옷·가면, 통나무 던지기/가슴 두드리기 충격파)
- 우주: 은하 파괴자 제노크 (거대 외계 함선형 촉수 괴수, 눈 여러 개, 레이저/운석 소환)
- 캔버스 그리기 함수로 위 품질 기준(그라데이션·발광·실루엣·대기 애니메이션·피격·손상·처치 연출)을 지켜 크게 그림. 등장 시 화면 위쪽에 보스 이름 카드(칭호+이름). 진행자 경주판에 보스 처치 소식 팝업 이름도 새 이름으로.

## C. 추격자 (arena-chase.js/.css 만, 그리고 arena-mission.js 의 드론은 그대로)
- 로봇 경주: 단계(modeState.stage 1~6)마다 추격 로봇이 진화: 1 정찰 로봇 스카우트, 2 사냥 로봇 헌터, 3 중장갑 로봇 탱커, 4 강습 로봇 블레이드, 5 거대 로봇 콜로서스, 6 최종 병기 오메가 타이탄. 단계마다 크기·무장·색·눈빛이 확실히 다르고 점점 거대하고 위협적으로(바퀴→다리→부스터 비행 등). 단계가 오를 때 새 추격자 등장 인트로(이름 카드). 거리가 가까워지면 눈빛·경고 강화. HUD 의 "로봇에게서 탈출하라" 문구에 현재 추격자 이름 반영.
- 잠수함 특공대: 추격자를 "심해의 지배자 레비아탄"(거대 바다뱀/아귀 혼합, 발광 미끼, 이빨은 과하지 않게)으로 화려하게. 게임 시작 때 인트로 카드, 거리가 가까울수록 입을 벌리고 화면이 어두워짐.
- 학생 화면 띠의 작은 그림도 같은 디자인의 아이콘.
